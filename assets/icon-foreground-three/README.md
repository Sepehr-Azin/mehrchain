# آیکون سه‌بعدی مهرچین

بازسازی `../icon-foreground.png` با Three.js، شامل بدن گرد سبز، دست‌های زرد، چشم‌های براق، حالت‌های چهره و شکم نورانی. تمام اجزای کاراکتر مش سه‌بعدی هستند؛ تصویر اصلی فقط در پنل مقایسه نمایش داده می‌شود. فرم پشت و ضخامت مدل از نمای روبه‌رو تخمین زده شده‌اند.

## اجرا

از ریشهٔ پروژه:

```powershell
npm --prefix assets/icon-foreground-three ci
npm --prefix assets/icon-foreground-three start
```

سپس `http://127.0.0.1:4310` را باز کنید. برای پورت دیگر، قبل از اجرا `$env:PORT = '4311'` تنظیم کنید. باز کردن مستقیم HTML با `file://` مناسب نیست؛ ماژول‌ها به سرور محلی نیاز دارند. پس از نصب، پیش‌نمایش به اینترنت احتیاج ندارد. این نمونه وابستگی‌های مستقلی دارد و وارد مسیرها یا بیلد برنامهٔ Angular نشده است.

## پیش‌نمایش

- کشیدن مدل برای چرخش؛ اسکرول یا حرکت دو انگشت برای زوم.
- «نمای اصلی» چرخش و حرکت را متوقف می‌کند و زاویهٔ روبه‌رو و حالت مرجع را برمی‌گرداند.
- سه حالت «مرجع»، «خوشحال» و «ناراحت» موجود است. مرجع لبخند کوچک تصویر اصلی را نگه می‌دارد.
- دست‌ها در حالت خوشحال به طور خودکار و بسیار ملایم، حداکثر حدود ۱٫۴ درجه، حرکت می‌کنند. در حالت مرجع و ناراحت ثابت‌اند.
- حرکت آرام شامل شناوری و پلک زدن است؛ به صورت پیش‌فرض خاموش است. حرکت خودکار حالت خوشحال به تنظیم کاهش حرکت مرورگر احترام می‌گذارد.
- شدت نور شکم، پس‌زمینه و نمایش مرجع قابل تنظیم‌اند.
- پنل مقایسه، مرجع و مدل را کنار هم با مقیاس یکسان و دوربین روبه‌رو نمایش می‌دهد.
- «ذخیره PNG شفاف» نمای فعلی را در اندازهٔ ۱۰۲۴ × ۱۰۲۴ با قاب آیکون مرجع و پس‌زمینهٔ شفاف ذخیره می‌کند؛ لینک دانلود هم در صفحه باقی می‌ماند.

## استفادهٔ دوباره از مدل

`mascot.js` از DOM مستقل است. در محیط دارای Three.js:

```js
import { createMascot } from './mascot.js';

const mascot = createMascot({ glow: 1, mood: 'reference' });
scene.add(mascot.model);
mascot.setMood('happy'); // reference | happy | sad

// در حلقهٔ رندر؛ زمان بر حسب ثانیه:
mascot.update(elapsedSeconds, true);
mascot.setGlow(1); // بازهٔ ۰ تا ۲

// فقط حرکت ظریف دست‌های خوشحال، بدون شناوری:
mascot.update(elapsedSeconds, false, true);

// هنگام حذف صحنه یا کامپوننت:
mascot.dispose();
```

مدل رو به محور `+Z` قرار دارد؛ ابعاد تقریبی آن `2.6 × 2.15 × 1.3` واحد است. هر ۱۸۰ پیکسل مرجع برابر یک واحد مدل است. نورهای صحنه و محیط بازتاب را مانند `preview.js` در مصرف‌کننده تنظیم کنید. بدنه از منحنی‌های Bézier برازش‌شده بر ۳۹ اندازه‌گیری تصویر و `LatheGeometry`، شکم از مش منطبق بر سطح بدن و دست‌ها از سطوح بسته ساخته شده‌اند. دوربین Orthographic نسبت سر، چشم و شکم را در نمای اصلی حفظ می‌کند. هالهٔ شکم، نرمی نور لبه‌ها و تاج سر با اصلاح شیدر متریال بدن ایجاد می‌شوند؛ تکسچر تصویر و فایل مدل خارجی نیاز نیست. سایهٔ بیضی زیر کاراکتر در `preview.js` مستقل از مدل ساخته می‌شود.

فایل‌های اصلی:

- `mascot.js`: هندسه، متریال‌ها، انیمیشن و آزادسازی منابع.
- `preview.js`: صحنه، نورها، دوربین، کنترل‌ها و خروجی PNG.
- `serve.cjs`: سرور محلی محدود به پوشهٔ پیش‌نمایش و تصویر مرجع.

مرجع متریال: [مستندات رسمی MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html).
