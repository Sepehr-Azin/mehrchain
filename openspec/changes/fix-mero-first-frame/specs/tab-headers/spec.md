## ADDED Requirements

### Requirement: Focused primary tab headers

Home, Chain, and Journey SHALL omit header Mero avatars, profile shortcuts, and appearance toggles, with companion and appearance controls available in Profile.

#### Scenario: Viewing a primary tab

- **WHEN** the user opens Home, Chain, or Journey
- **THEN** its header SHALL contain the page title and supporting text without the redundant controls
- **AND** global Profile navigation and Profile's companion and theme settings SHALL remain available.
